# Speed — Internet Speed Test

Минималистичный тест скорости интернета в стиле Apple (чёрно-белый).

## Возможности

- Спидометр с живой стрелкой
- Download / Upload / Ping
- IP-адрес, страна, флаг, город, провайдер
- Работает через Cloudflare Edge

## Деплой на Vercel

1. Загрузи этот репозиторий на GitHub
2. Зайди на [vercel.com](https://vercel.com)
3. Import Project → выбери этот репозиторий
4. Deploy

Готово.
